# 首次配置与个人定制

## 触发、保存与恢复

Skill安装不会自行运行问答；在安装完成后的首次调用检查本机配置。有配置就直接使用，只有用户要求“重新定制/修改配置”或实际必需项缺失时再问。无配置时先继承本会话已有明确决定，再问：“是否进行个性化定制？否：用默认素材随机制作；是：配置人设、模板、形象、音色等。”提供“否，直接用默认”“是，开始定制”两项；明确选择前不替用户作答。用户本次明确说直接按默认制作，等同选否。

本机配置位置：`$CODEX_HOME/marketing-video-local/profile.json`，未设置CODEX_HOME时用 `~/.codex/marketing-video-local/profile.json`。用实际环境展开路径，不写死账号目录。自定义图片、试听和形象方案放该目录下的 `assets/`；制作工程仍放项目目录。不要写进skill的公共assets或Git仓库，不覆盖旧素材和已有配置。

配置至少记录 `schema_version: 1`、`setup_status`（in_progress/completed）、`mode`（default/custom）、当前步骤及已回答的偏好。偏好包括persona、template、avatar、voice、catchphrases、delivery和packaging；明确禁用项记为false，跳过项记为default。语音配置只记录服务/模型/voice_id、音色处理参数及密钥环境变量名，不存密钥值。已有文件先读后合并，只更新本次用户指定字段。未完成时从未答步骤继续，不重新开始。配置损坏时保留原文件并说明问题，不静默重置。用户修改后保存，并用短摘要告知实际生效项。

选否：保存completed/default并保留已确认偏好；不再追问下面的可选项目，立即推进用户的制作任务。选是：逐步收集，每轮最多三组问题，优先给选项和“沿用默认/跳过”，用户可一次回答全部；只追问影响结果的缺口。可用异步问题工具收集文本选择；需要图片时在普通对话请求附件或本地路径。等待必需回答时继续检查素材等独立工作，不把未回答当同意。若用户说“剩下默认”，立即结束配置。

## 定制步骤

1. **人设与定位**：问账号名称是否展示、内容领域/目标受众、解说者身份与说话风格（客观串联、幽默吐槽、产品演示或自定义）。可仅定义叙述口吻，无需虚构主持人经历。保持事实底线，不为人设编造亲历。
2. **模板与视觉**：问随机合适模板、固定参考模板，或按用户新参考定制；随机可以设喜欢/排除范围。收集背景、主色、字幕大小/位置和logo需求，没意见就默认。固定的是视觉结构，不套用旧字幕、水印和旧事件。不要逐个要求用户挑所有素材。
3. **可选出镜形象/角色模型**：明确这里指画面中的主持人、虚拟角色或立绘，不是语言模型。先问是否要；不要就跳至音色。要则问真人/卡通/其他外观、服装与出镜形式（立绘、动态角色或口播），让用户提供图片/路径或选择生成。使用可用图像工具生成前形成具体方案；缺少视频/口型能力则说明可实现形态，不把静态图称为会说话的模型。生成新图片时按可用imagegen skill执行；外部服务费用超出已有授权时先取得相应授权。若用户所说“模型”其实是生成模型/API，则按其意思询问用途、服务及模型配置，不擅自更改Codex运行模型。
4. **音色与生成服务**：提供默认可用通用中文音色、已有授权音色或自定义服务。自定义时请用户给音色生成API链接/官方说明、服务及模型名称、voice_id，必要时核对接口；参考录音不是voice_id，不保证任意接口支持复刻。密钥通过本机环境变量配置，不索要聊天明文，不写公共仓库。用户选择音色复刻时使用其有权使用的录音，核实服务实际支持。音高/语速可独立设置；沿用已认可尖嗓快语速时按event-default-workflow.md处理，仅作用于旁白。新音色先做短试听，用户认可后再生成长稿；已有认可音色不重复试听。无可用默认语音服务时说明缺口，不冒称安装自带音频或已完成配音。
5. **口头禅**：先问要不要；不要就跳过，要则收集具体用语、用于开头/转场/结尾以及频率。可给简短候选供选择。默认使用现有开场句式库，不逐句重复；个人口头禅可调整开场，但不能插入原声、伪装当事人发言或添加无依据结论。
6. **其他偏好**：集中问发布平台/画幅/大致时长、字幕样式、BGM类型与禁用曲目、表情包密度、开场放大/音效强度、结尾互动和输出目录；提供“全部默认”选项。可设置避免使用的词、主题、角色或素材。关键原声默认关添加的BGM、暂停旁白，并保留原意及真实事件关系。补充是否保留工程和来源记录时默认保留，发布文案/标签默认随成片交付。不要把账号登录、自动发布或额外服务购买混进定制授权。

结束时给一份简短配置摘要，直接进入原制作任务。除新音色/形象确需选择外，不增加整份配置的批准关卡。用户只要求配置时，保存后交付摘要即可，不自动生成视频。

## 默认模式与优先级

默认不添加出镜形象、账号名或logo。按题材从实际可用的默认素材中随机挑兼容模板/装饰，优先相关动态视频、适量动态表情包；记录本次模板/素材选择便于复现。随机只影响包装选择，不随机改变事实、事件顺序或回应关系。没有BGM音频或模板时采用可用的简洁布局/无BGM方案，不虚构已使用公共索引中的本机资源。

事件类默认按event-default-workflow.md：素材先行，旁白串联，尖嗓快语速，关键原声关添加的BGM；本机无原作者复刻音色时选实际可用的通用音色并说明，不能承诺公共安装自动获得私人voice_id。默认9:16，时长由可支持的信息决定；字幕清晰、画面不持续抖动，BGM不盖配音，自动附发布文案与相关标签。正常配置完成后不再次问是否定制，用户随时可说“改音色”“换模板”“取消形象”“恢复默认”；恢复默认只重置偏好，不删除用户素材。

优先级：本次用户明确要求 > 已保存个人配置及仍有效的对话决定 > 通用默认。风格偏好不覆盖事实性内容底线。公共skill更新只替换规则与公共资源，个人配置独立保留；不要为本次规则更新预先替当前用户选择定制模式。
