# 营销号视频 Codex Skill

把你提供的话题、视频、图片或产品资料制作成中文短视频，完成素材选择、文案、配音、字幕、剪辑和成片检查，并自动附上发布文案与话题标签。支持事件解说、趣味吐槽、网络梗解说和产品种草。

## 安装与更新

在 Codex 中发送：

> 使用 $skill-installer 安装 https://github.com/sunzhaocn/marketing-video-skill/tree/main/marketing-video 中的 skill。

音乐文件采用48 kbps MP3压缩格式，62首约70 MiB，直接随仓库下载，无需Git LFS。skill素材合计约406 MiB（不含仓库演示视频）；请等待下载完成并检查音频实际存在。已安装旧版时，可让Codex更新BGM及索引，保留个人配置和自添素材。

安装后下一轮可以使用 `$marketing-video`。安装本身不会启动定制问答，也不会自动安装配音或视频工具。

本地已有同名 skill 时，安装器会停止以防覆盖。更新可以这样说：

> 更新 GitHub 上的 marketing-video skill，保留我自己添加的素材和本机个人配置，比较后合并。

## 开始制作

提供话题或素材文件，再发送：

> 使用 $marketing-video，把这些素材做成一条视频，模板随机选择，完成配音、字幕和剪辑，并附发布文案与标签。

也可以明确本次要求，例如：

> 使用 $marketing-video，先选关键素材，再写旁白串联。保留尖嗓快语速和动态表情包，关键原声段关闭BGM，图片不要持续抖动。

本次明确要求优先于个人配置，个人配置优先于通用默认。时长由实际可支持的信息决定，不靠重复口播或未经证实的细节凑长。制作请求不包含自动上传平台。

## 首次使用：默认或自定义

没有已保存配置时，首次调用会询问是否个性化定制。已有明确偏好会继承，不重复询问。

- **否，直接用默认**：从实际可用素材中随机选择适合题材的模板与包装，直接制作。
- **是，开始定制**：按下面的顺序配置；每项都能跳过，也可以说“剩下默认”。

| 项目 | 可以定制的内容 |
| --- | --- |
| 人设与定位 | 账号名称、内容领域、受众、叙述身份与说话风格 |
| 模板与视觉 | 随机或固定参考、背景、配色、字幕、logo |
| 可选出镜形象 | 是否需要主持人/虚拟角色；提供图片或选择生成，设定外观及出镜形式 |
| 音色 | 默认可用音色、已有授权音色或自定义API；音高、语速及短试听 |
| 口头禅 | 是否启用、具体用语、出现位置和频率 |
| 其他偏好 | 发布平台、画幅、时长、BGM、表情包密度、音效、结尾互动、输出位置与禁用素材 |

“形象/角色模型”指画面中的角色。动态角色、口型及自定义语音需要实际可用的生成服务；提供参考图片或录音不代表已经获得这些能力。自定义音色可提供API链接/官方说明、服务模型和voice_id，密钥在本机单独配置。

## 随时修改与人设迁移

直接告诉 Codex：

> 以后默认改成幽默吐槽人设，保留音色，减少表情包。

> 这条视频临时换模板，其他配置不变。

> 给我人设文件，方便导入另一台电脑。

> 导入这份人设配置，保留我没有指定修改的项目。

导出包含：

- `人设配置.json`：用于导入的配置文件。
- `人设说明.md`：便于阅读的偏好摘要、导入说明和缺失依赖。
- `人设导入包.zip`：有自定义图片等附件时一并打包；也可主动要求便携包。

导入前备份现有配置，默认合并明确提供的字段。缺少素材或音色服务会列出，不冒称已恢复全部能力。密钥、令牌和账号登录信息不放进导出包；voice_id在新设备或不同账号下仍需验证权限与可用性。

个人配置保存在 `$CODEX_HOME/marketing-video-local/profile.json`；未设置CODEX_HOME时使用 `~/.codex/marketing-video-local/profile.json`。个人附件在同目录的 `assets/`，导出默认放 `exports/`。这些内容独立于公共skill，更新不会覆盖，也不自动上传GitHub。随时可以说“修改配置”或“恢复默认”；恢复默认不删除用户素材。

## 事件类默认制作方式

1. **先选素材**：挑关键发言、原帖与必要背景，记录来源、入出点、时间及回应对象。
2. **再写旁白**：只补充背景与过渡，让原素材呈现关键内容，避免旁白、原帖和报道重复同一信息。
3. **声画配合**：保留尖嗓快语速旁白、相关动态视频及适量动态表情包。关键原声段暂停旁白、关闭添加的BGM，原声保持原速原音高。
4. **简化包装**：主体画面、必要字幕和来源标注为主，减少重复摘要卡与章节编号；可用短开场放大、大字幕和音效，普通画面不持续抖动。
5. **交付成片**：核对内容与媒体，保留文案、字幕、时间线/工程和来源记录，附发布文案与相关标签。

**可以剪短，不能剪变意思；可以重排叙事，不能制造虚假的时间顺序或回应关系。**

公共安装不包含原作者私人复刻音色和密钥。实际音色由本机配置决定；缺少服务时说明缺口，不用静音预览冒充完整配音成片。关键原声关闭的是额外添加的BGM，原素材内部已有音乐需单独处理。

## 素材库与自行补充

仓库包含507个表情包（133个动态、374个静态）、10张背景/图文参考素材，以及编号预览和格式索引；另含16个视频模板参考成片（约127 MiB）。视频模板用于参考结构，旧字幕、水印和旧事件不能直接套进新视频。部分背景图是图文参考拼图，使用前需检查。

另从269条用户参考视频中精简保留14条段子、网友热评与科技解说案例（约18 MiB），配有索引及两张预览。制作这些题材时按需读取 [段子与热评制作方法](marketing-video/references/humor-comment-workflow.md)，学习铺垫、逐步揭示、包袱回扣与画面分工；不会把样例的旧品牌、历史笑话或产品说法当成新稿事实。

把新素材放进**本机安装的skill目录**，再让 Codex 检查和更新索引：

| 素材 | 存放目录（相对skill根目录） | 更新方式 |
| --- | --- | --- |
| 表情包 | `assets/表情包/` | `scripts/index_assets.py` 更新索引与预览 |
| 背景/参考图 | `assets/背景素材/` | `scripts/index_assets.py` 更新索引与预览 |
| 视频模板 | `assets/视频模板/` | 让Codex检查并更新独立视频索引与预览 |
| 结构参考案例 | `assets/参考案例/` | 让Codex检查并更新 `reference-case-index.json` 与预览 |
| BGM音频 | `assets/BGM/` 对应分类 | `scripts/index_bgm.py` 更新音乐索引 |

例如：

> 我在素材库里加了新素材，请检查可用性并更新索引，以后制作时可以使用。

BGM包含8类选曲规则、62首曲目索引及**48 kbps MP3音频（约70 MiB）**，直接随仓库提供；实际有音频才会选用。没有音乐时可制作无BGM版本。静态与动态素材按真实格式区分，动画保留逐帧时长。最初分析的示例视频及新闻截图不随仓库发布；公开的两条测试成片放在仓库 `demo/`，与安装用的skill素材分开。

长期个人偏好用“修改配置”保存；公共制作规则放在 `references/` 并从 `SKILL.md` 链接。一次事件的源素材和成片保留在项目内。

## 运行条件

媒体合成可使用 FFmpeg/ffprobe；素材索引需要 Python、Pillow 和可用中文字体（如微软雅黑、苹方或 Noto Sans CJK）。字体文件不随仓库提供。配音、转写、图像或角色生成服务按实际任务配置，外部付费服务按用户授权使用。

曾测试通用中文TTS `edge-tts`，需要网络，每次使用仍须验证可用性；也支持用户提供的配音及自定义语音API。工具或服务不可用时会说明已完成项和具体缺口。

素材由用户提供；本仓库未为第三方图片、角色、表情包或音乐授予额外版权许可，使用者应根据用途确认使用权限。

## 音乐压缩与历史清理

当前62首BGM为48 kbps、22.05 kHz单声道MP3，约70 MiB，以减小下载体积为优先，音质低于原文件。全部素材约388 MiB，无需Git LFS。旧无损和192 kbps音乐版本已从分支历史移除；历史已重写，旧克隆建议备份自添内容后重新克隆，避免把旧历史推回仓库。下载当前ZIP或浅克隆可取得压缩后的版本。

GitHub旧LFS对象的服务器存储不会因改写历史自动释放，但新克隆不再引用或下载它们。彻底删除远端LFS实体需按[GitHub官方说明](https://docs.github.com/en/repositories/working-with-files/managing-large-files/removing-files-from-git-large-file-storage)联系支持或删除并重建仓库；本次保留仓库，未执行删除重建。
