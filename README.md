# 营销号视频 Codex Skill

根据素材制作中文趣味解说、网络梗解说、产品种草视频，涵盖文案、配音、字幕、剪辑和成片检查。

内含507个表情包（133个动态、374个静态）、10张用户提供的背景/图文参考素材，以及编号预览和真实格式索引。另含15个视频模板参考成片（约121 MiB），可参考标题、窗口、字幕和混剪结构；安装时请等待下载完成。

## 安装

在 Codex 中发送：

> 使用 $skill-installer 安装 https://github.com/sunzhaocn/marketing-video-skill/tree/main/marketing-video 中的 skill。

安装后下一轮可以使用 `$marketing-video`。如果本地已有同名 skill，安装器会停止以防覆盖；更新时先保留自己添加的素材和要求，再由 Codex 比较合并。

## 使用

> 使用 $marketing-video，读取我提供的素材，参考示例风格完成文案、配音、字幕、剪辑和成片；普通创作选择由你决定，缺少必须核实的信息时再问我。

首次调用会询问是否个性化定制。选“否”直接使用可用默认素材随机制作；选“是”依次配置人设、模板、可选出镜形象、音色、口头禅及字幕/音乐/平台等偏好。配置仅保存在本机独立目录，后续沿用，更新skill不会覆盖；随时可以说“修改配置”或“恢复默认”。安装本身不会自动弹出问答。

`marketing-video/SKILL.md` 是入口。通用制作规则随仓库提供，最初用于分析的示例视频、新闻截图和测试成片不随仓库发布，请在制作时提供自己的参考与素材。

## 自行补充

- 表情包放到 `marketing-video/assets/表情包/`。
- 背景或参考图放到 `marketing-video/assets/背景素材/`。
- 视频模板参考成片放到 `marketing-video/assets/视频模板/`；请让 Codex 检查并更新独立视频索引和预览。
- 长期制作要求写入 `marketing-video/references/`，并在 `SKILL.md` 中链接。
- 新素材的索引与编号预览可由 Codex 执行 `scripts/index_assets.py` 更新。

## 运行条件

Skill 是给 Codex 的工作指引，安装本身不会自动安装视频或配音工具。媒体合成可使用 FFmpeg/ffprobe；索引脚本需要 Python、Pillow 和中文字体（微软雅黑、苹方或 Noto Sans CJK）。字体文件不随仓库提供。

测试过通用中文 TTS `edge-tts`，需要网络，未来执行时仍须验证服务是否可用；也可以使用自己提供的配音。语音生成、转写等可选工具按实际任务安装。无法使用的工具须如实说明，不能把静音预览称作完整配音成片。

背景压缩包的10张图主要是图文参考拼图，不一定适合直接铺作视频背景。静态图片与动画按真实文件格式区分，GIF 保留逐帧时间。

素材由用户提供；本仓库未为其中的第三方图片、角色或表情包授予额外版权许可，使用者应根据具体用途确认使用权限。

## BGM音乐库

包含8类选曲规则、62首本地曲目的索引及完整解码检查结果。歌曲文件仅供本地使用，不随公开仓库发布。自行把音频放入 marketing-video/assets/BGM 的对应分类目录，使用 scripts/index_bgm.py 更新索引；规则见 references/bgm-selection.md。
